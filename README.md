# DRNOS
A specialized operating system designed for mechanical entities, optimized to enhance performance on legacy and resource-constrained hardware architectures. In layman’s terms, DRN put in an operating system for mechanical beings who can’t function on other operating systems.

This OS is made by fauxhaunt. Original DRN by Errant Spark: https://errantspark.com/drn/
